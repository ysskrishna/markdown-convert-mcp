# Security policy

## Reporting a vulnerability

This is an MIT open-source project. Please do not open a public issue for a security problem.

Report it privately through GitHub: open the [Security tab](https://github.com/ysskrishna/markdown-convert-mcp/security) and choose **Report a vulnerability**. Include what you found, how to reproduce it, and the MCP host and package version you used.

You can expect a first reply within 7 days. If the report is confirmed, a fix ships in a new release and the CHANGELOG credits you unless you ask not to be named.

## Supported versions

Only the latest release receives security fixes.
